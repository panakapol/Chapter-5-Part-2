🎯 ANOVA คืออะไร ใช้เมื่อไหร่

ใช้ทดสอบว่า ค่าเฉลี่ยของประชากรตั้งแต่ 3 กลุ่มขึ้นไป ที่เป็นอิสระต่อกันแตกต่างกันหรือไม่ โดยตัวแปรตาม (สิ่งที่วัด) เป็นเชิงปริมาณ และตัวแปรอิสระ (ตัวจำแนกกลุ่ม) เป็นเชิงจำแนก

📐 ข้อตกลงเบื้องต้น (Assumptions)

  • ตัวอย่างแต่ละกลุ่มถูกสุ่มมาจากประชากรที่ เป็นอิสระกัน
  • ตัวอย่างทุกกลุ่มมาจากประชากรที่มีการแจกแจงแบบปรกติ
  • ตัวอย่างทุกกลุ่มมาจากประชากรที่มีความแปรปรวนไม่ต่างกัน (เท่ากัน)
ทดสอบการแจกแจงปรกติ:
Kolmogorov–Smirnov (n > 50)
Shapiro–Wilk (n ≤ 50)
H₀: ข้อมูลแจกแจงแบบปรกติ
ทดสอบความแปรปรวนเท่ากัน:
Levene's test
H₀: ทุกกลุ่มมีความแปรปรวนเท่ากัน
ถ้า p-value ของทั้งสองการทดสอบข้างต้น > α (0.05) แปลว่า ไม่ปฏิเสธ H₀ → ข้อมูลเป็นไปตามข้อตกลง → ใช้ One-way ANOVA ได้เลย

🔍 การเปรียบเทียบพหุคูณ (Multiple Comparison / Post-hoc)

ทำต่อเฉพาะเมื่อปฏิเสธ H₀ จาก ANOVA แล้ว เพื่อดูว่าคู่ใดบ้างที่ค่าเฉลี่ยต่างกัน

วิธีเงื่อนไขการใช้
LSD (Least Significant Difference)เปรียบเทียบค่าเฉลี่ยได้ครั้งละหลายคู่ (error สะสมง่ายกว่าวิธีอื่น)
Tukey's HSDตัวอย่างแต่ละกลุ่มขนาดเท่ากัน
Scheffeตัวอย่างแต่ละกลุ่มขนาดเท่ากันหรือไม่เท่ากันก็ได้
Bonferroniจำนวนกลุ่มตัวอย่างไม่เกิน 5 กลุ่ม
LSD = t₍α/2, ν₎ · √( MSE · (1/nᵢ + 1/nⱼ) )

เกณฑ์: ถ้า |X̄ᵢ − X̄ⱼ| ≥ LSD → คู่นั้นแตกต่างอย่างมีนัยสำคัญ ถ้าน้อยกว่า → ไม่แตกต่าง

🎯 ข้อมูลเชิงจำแนก (Categorical Data)

การทดสอบไคสแควร์ใช้กับข้อมูลที่เป็นเชิงคุณภาพอย่างน้อย 1 ตัว โดยข้อมูลอยู่ในรูป จำนวนนับ (Count data)

นามบัญญัติ (Nominal)

เช่น เห็นด้วย/ไม่แน่ใจ/ไม่เห็นด้วย — มีลำดับ

🧩 การทดสอบไคสแควร์ 3 แบบ — ต่างกันอย่างไร

ประเภทสมมติฐาน H₀df
Test of Independenceตัวแปร A และ B ไม่มีความสัมพันธ์กัน (เป็นอิสระต่อกัน)(r−1)(c−1)

Goodness-of-fitประชากรมีการแจกแจงตามที่ระบุk−1−m

🧮 ตัวสถิติทดสอบ

χ² = ΣΣ (Oᵢⱼ − Eᵢⱼ)² / Eᵢⱼ
Eᵢⱼ = (Oᵢ.)(O.ⱼ) / n = (Oᵢ.)(O.ⱼ) / O..

m ใน Goodness-of-fit คือจำนวนพารามิเตอร์ที่ต้องประมาณค่าจากข้อมูล (เช่น ประมาณ λ ของ Poisson ใช้ X̄ → m=1)

เกณฑ์ตัดสินใจ: ปฏิเสธ H₀ ถ้า χ² ≥ χ²₍α,ν₎  หรือ  p-value ≤ α

⚠️ กฎการยุบเซลล์ (Cell Merging) — สำคัญมาก มักออกสอบ

Yate's Correction: χ² = ΣΣ (|Oᵢⱼ − Eᵢⱼ| − 0.5)² / Eᵢⱼ
ใน SPSS ดูที่ footnote ใต้ตาราง "Chi-Square Tests" เช่น "1 cells (16.7%) have expected count less than 5" — ถ้าเปอร์เซ็นต์นี้ ไม่เกิน 20% ยังใช้ผลทดสอบได้ตามปกติ

👔 ตัวอย่างละเอียด 1: ภาวะการเป็นผู้นำ × เพศ (Test of Independence, จากสไลด์หน้า 169-172)

โจทย์: สุ่มผู้บริหาร 75 คน วัดภาวะการเป็นผู้นำ 3 ระดับ (มาก/ปานกลาง/น้อย) จำแนกตามเพศ จงทดสอบว่าเพศและภาวะการเป็นผู้นำมีความสัมพันธ์กันหรือไม่

χ² = Σ(Oᵢ−Eᵢ)²/Eᵢ = 2.118   df = k−1−m = 7−1−1 = 5
5
p-value = P(χ²₍₅₎ > 2.118) = 0.8326 ซึ่งมากกว่า α=0.05 → ยอมรับ H₀
สรุป: จำนวนครั้งที่ร้องขอค่ารักษาพยาบาลมีการแจกแจงสอดคล้องกับปัวซอง ที่ระดับนัยสำคัญ 0.05
